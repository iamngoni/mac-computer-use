Let your agent use your Mac, without taking it from you.

Mac Computer Use is a small Mac app that lets Claude Code, Codex, Cursor, Gemini CLI and other MCP clients see and use your apps. It works in the background, leaves your pointer alone, and stops the moment you press esc.

Below is a sketch of an agent at work, drawn in your browser with the app's own cursor. Your pointer is yours the whole time.

Mac Computer Use gives an agent eyes and hands on your Mac, through the same Accessibility interface that screen readers use. It works beside you, not instead of you: clicks go to the right window in the background, and your pointer stays where you left it. Every window is checked before anything happens, so an agent can't click into the wrong app. And you're always in charge: risky buttons wait two seconds for you, and Esc stops every agent at once.

Background, not takeover

Clicks use the app's own Accessibility actions where possible. Typing, scrolling and dragging go to one checked window. You keep working in another.

Permissions, once

You grant Accessibility and Screen Recording to Mac Computer Use, not to every agent. The first time a new client tries to act, the app asks you, and it remembers that client by its code signature.

An agent you can see

Its cursor flies to each target before acting. It can point at things, draw on screen, ask you a question, or hand you a password step and wait.

Stops when you say so

esc pauses every agent. Send, Delete and Buy get a two-second countdown you can cancel. Agents wait while you're using the same app.

Set up in a few minutes.

  1. 1

    Install

    Open the DMG and drag Mac Computer Use into Applications. It lives in the menu bar and updates itself between tool calls.

  2. 2

    Grant two permissions

    The setup window shows whether Accessibility and Screen Recording are on, and opens the right System Settings pane for each.

  3. 3

    Connect your agent

    Setup registers Claude Code or Codex with one click. It speaks plain MCP over stdio, so any agent that takes an MCP server works too:

    claude mcp add --scope user mac-computer-use -- \
  "/Applications/MacComputerUse.app/Contents/MacOS/mac-computer-use" mcp
    codex mcp add mac-computer-use -- \
  "/Applications/MacComputerUse.app/Contents/MacOS/mac-computer-use" mcp
    gemini mcp add --scope user mac-computer-use \
  "/Applications/MacComputerUse.app/Contents/MacOS/mac-computer-use" mcp

    Add to ~/.cursor/mcp.json, then turn it on under Settings → MCP.

    {
  "mcpServers": {
    "mac-computer-use": {
      "command": "/Applications/MacComputerUse.app/Contents/MacOS/mac-computer-use",
      "args": ["mcp"]
    }
  }
}

    Then use it from Copilot Chat in agent mode.

    code --add-mcp '{"name":"mac-computer-use","command":"/Applications/MacComputerUse.app/Contents/MacOS/mac-computer-use","args":["mcp"]}'

    Claude Desktop, Windsurf, Zed, Cline and other clients take this stdio server config.

    {
  "mcpServers": {
    "mac-computer-use": {
      "command": "/Applications/MacComputerUse.app/Contents/MacOS/mac-computer-use",
      "args": ["mcp"]
    }
  }
}

Questions

Does it move my mouse?

No. Clicks, scrolling and dragging go to a checked app and window without moving your pointer. The agent's cursor is drawn separately. Agents can control the whole desktop only when they ask for it explicitly with allow_global_input.

Which permissions does it need?

Accessibility and Screen Recording, granted once to Mac Computer Use. Claude Code, Codex, Cursor and other clients never need them. The app asks you once per client before it may act.

How do I stop an agent?

Press esc. Every agent pauses until you resume from the menu bar, and the interrupted action reports that you stopped it. Quitting the app turns automation off.

Is it free?

Yes. It's open source, needs no account, and signed releases update themselves.

Which Macs does it run on?

macOS 13 Ventura or later, on Apple silicon and Intel. Whole-desktop capture needs macOS 14.
